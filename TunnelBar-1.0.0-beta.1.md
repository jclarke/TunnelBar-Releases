TunnelBar 1.0.0 beta 1

Initial public beta for TunnelBar.

- Manage local ngrok tunnels from the macOS menu bar.
- Change tunnel ports without manually editing ngrok config files.
- Start, stop, and restart ngrok from native macOS controls.
- View configured tunnels, active forwarding URLs, connection metrics, and recent HTTP requests.
- Create timestamped config backups before changes.
- Store saved tunnel groups for repeated local workflows.
